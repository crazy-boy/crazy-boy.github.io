## 用来做什么

比对两份 SQL 文件，生成表结构及数据变更脚本，包括新建或删除表、字段和索引变化，以及 INSERT、UPDATE、DELETE 数据变更。

## 快速开始

1. 下载并双击运行 diff_tool.exe，首次启动请稍等片刻。
2. 选择文件 A、文件 B，再选择比对方向：**旧文件 → 新文件**。
3. 点击“刷新表列表”，按需选择排除的表或忽略字段。
4. 点击“生成 diff 结果”，在目标文件所在目录查看 result.sql；该目录需有写入权限。

## 比对选项

- **排除数据比对的表**：只比对结构。
- **整表排除**：结构和数据都不比对。
- **忽略字段**：默认忽略 created_at、updated_at。
- 更换文件或方向后，需要再次刷新表列表。

## 使用前了解

生成结果需要人工核对，可能包含删除表或删除数据的语句。执行前请备份数据库并在测试环境验证，不要重复执行生成脚本。

根据原始说明，目前只解析每行一条的 CREATE TABLE 和 INSERT INTO；多行 INSERT、REPLACE 等写法可能无法正确解析。数据匹配优先使用主键的第一列，没有主键时回退到第一列。
