## 快速开始

1. 下载并双击运行 `Morrow.exe`，无需安装 Node.js 或 Python。
2. 在顶部输入任务并按回车，使用设置中的默认截止时间；点击加号可填写内容和截止时间。
3. 使用 `Ctrl+Shift+M` 显示或隐藏快捷面板。按 Esc 或切换到其他窗口也可隐藏，程序会保留在系统托盘。

## 管理任务

- 勾选任务标记为已完成，双击或点击铅笔图标修改任务。
- 右键或点击垃圾桶图标删除任务。
- 按“全部任务 / 今天到期 / 已延期 / 已完成”筛选，搜索框即时过滤。
- 在齿轮设置中调整快捷键、默认截止时间和周期提醒。

## 办公工具识别

默认关闭。可在设置中分别启用飞书、企业微信、钉钉、微信、QQ，并配置称呼和识别规则。规则确认后，还需在主设置中点击“保存”。

启用后每 3 秒检查已选工具的前台聊天窗口，首次打开聊天只建立基线。识别出的候选任务显示为“待确认”，点击“加入任务”后才写入任务列表，也可以忽略。识别效果受界面布局、缩放和 Windows 中文 OCR 组件影响。

## 数据保存

任务保存在当前 Windows 用户的 `%APPDATA%\TodoTool\data.json`，保存时保留上一版 `data.json.bak`。读取失败会提示错误并保留原文件。
