## 快速开始

1. 下载 `diff_tool.exe`，双击打开统一窗口。
2. 在顶部标签中选择 SQL、JSON、配置或文本。
3. 打开文件或在支持的页面粘贴内容，选择比对模式后开始比对。

## 支持的比对方式

| 类型 | 功能 |
| --- | --- |
| SQL | 选择新来源与旧目标，设置方向和排除项，生成 `result.sql` |
| JSON | 严格值、语义值、原文三种模式 |
| 配置 | 自动识别 INI 或键值配置，支持 `.properties`、`.env`，可按键或按原文比对 |
| 文本 | 逐行比对，包含空格和末尾换行变化 |

差异明细可展开或收起，也可使用“上一处 / 下一处”定位变化。

## 文件与结果

打开文件使用 UTF-8，支持 BOM；解码失败时会提示。JSON、配置和文本模式只读取输入，输入框中的编辑不会写回原文件。

SQL 生成的脚本可能包含 `DROP`、`DELETE`，执行前请核对内容。

下载提供窗口版 EXE 和原始 README。README 中的命令行与开发部分需要源码，EXE 用于图形界面操作。
