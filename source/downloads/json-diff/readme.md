# JSON 差异比对工具

适用于 Windows 10 / 11（64 位）。下载 json_diff_tool.exe 后直接运行，无需安装额外运行环境，支持离线使用。

本下载仅提供可执行程序和使用说明，不包含源代码。

## 用来做什么

在本地比对两份 JSON，支持粘贴文本或打开 UTF-8 JSON 文件，不修改输入文件。

## 快速开始

1. 下载并双击运行 json_diff_tool.exe，首次启动请稍等片刻。
2. 在“输入”页粘贴左右内容，或打开左右两份 JSON 文件。
3. 选择模式，点击“开始比对”。
4. 在“差异结果”页查看对齐内容，用“上一处 / 下一处”逐项定位。

## 如何选择模式

| 模式 | 适合的场景 |
| --- | --- |
| 严格值 | 默认模式，忽略空白和对象键顺序，但区分 1 与 1.0 等书写差异 |
| 语义值 | 忽略等价数字和字符串转义的书写差异 |
| 原文 | 按文本行对比，保留空格和缩进差异 |

## 阅读结果

绿色表示右侧新增，红色表示右侧删除，黄色表示值变化，橙色表示类型变化，蓝色表示含义相同而格式不同。

支持“仅显示差异”、双击复制 JSON 路径和 Ctrl+F 搜索。较大的结果分批显示，比对期间可以取消。

## 支持范围

- 对象键区分大小写，结构化模式忽略对象键顺序。
- 数组按下标比对，顺序变化也算差异。
- 缺少属性与属性值为 null 不相同。
- 重复键会报错；不接受注释、尾逗号、NaN、Infinity 等非标准 JSON。
