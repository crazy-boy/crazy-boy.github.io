## 验证与维护

```powershell
npm run clean
npm run build
npm run check:site
npm run check:books
```

`prebuild` 自动执行 `check:content`，校验文章日期、标题和重复 abbrlink。CI 执行全站生成结果和书籍检查。

检查通过：326 篇文章元数据，947 个主题页面的元信息和站内资源，79 页书籍导航。另用本地 Edge 实际验证了 17 个 Mermaid 图表、Shor 页的 15 处公式、手机目录、搜索、专题入口与桌面/手机排版。浏览器验证的临时脚本和截图归档在忽略目录 `.cleanup-backup/2026-10-17/.book-qa/`，不属于发布源码。

分类标签的大规模合并、Excel 重复笔记整合、历史短笔记扩写和技术结论逐篇核验属于后续内容编辑工作。本次没有批量迁移分类或删除历史博文。

项目依赖和遗留组件的精简见 [project-cleanup-2026-10-17.md](project-cleanup-2026-10-17.md)。
